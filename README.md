# אתגר 14 ימים: הוראות הפעלה

האפליקציה היא אתר סטטי שמתארח ב-GitHub Pages. הסימונים נשמרים בגיליון Google Sheets דרך סקריפט קטן.

## 1. הסקריפט בגיליון (פעם אחת)

1. פותחים את הגיליון "אתגר 14 ימים" ובוחרים Extensions, ואז Apps Script.
2. מוחקים את הקוד שיש שם ומדביקים את כל התוכן של `apps-script/Code.gs`. שומרים.
3. לוחצים Deploy, ואז New deployment, ובוחרים Web app.
4. בהגדרות: Execute as = Me, Who has access = Anyone. לוחצים Deploy ומאשרים את ההרשאות.
5. מעתיקים את הכתובת שמסתיימת ב-`/exec`.

## 2. הכתובת באפליקציה

בקובץ `config.js` מדביקים את הכתובת בין המרכאות של `API_URL`.

## 3. העלאה ל-GitHub

1. יוצרים ריפו חדש וציבורי (Pages בחינם דורש ריפו ציבורי).
2. מעלים את הקבצים: `index.html`, `app.js`, `config.js`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`.
3. ב-Settings, ואז Pages: Source = Deploy from a branch, Branch = main, תיקייה = root.
4. אחרי דקה או שתיים האתר זמין ב-`https://<שם-משתמש>.github.io/<שם-הריפו>/`.

## 4. התקנה בטלפון

כל אחד פותח את הקישור, בוחר את השם שלו, ומוסיף למסך הבית.
- אייפון, בספארי: כפתור השיתוף, ואז הוספה למסך הבית.
- אנדרואיד, בכרום: תפריט שלוש הנקודות, ואז התקנת אפליקציה.

## הערות

- שמות המשתתפים צריכים להיות זהים ב-`config.js` (PEOPLE) וב-`Code.gs` (PEOPLE). אם משנים, משנים בשניהם.
- הריפו ציבורי, ולכן הכתובת של הסקריפט גלויה. מי שמוצא אותה יכול לסמן במקום אחרים. בין חברים זה בסדר, אבל זו לא הגנה.
- הנתונים נשמרים בלשונית "נתונים" של הגיליון. הלשוניות הישנות לא מתעדכנות.
